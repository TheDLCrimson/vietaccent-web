# Changelog

All notable changes to VietAccent are listed here.

---

## v1.0.2 | Tone Weight Configuration

**Released: 2026-06-29**

### Improvements
- Testers can now configure how much pitch accuracy vs. text accuracy contributes to pronunciation scores: a new "Custom tone weight" toggle in Settings > Pronunciation reveals a slider (0-100%) that maps to the backend's tone_weight parameter
- Slider position is persisted across app restarts; toggling the feature off omits the field entirely, letting the backend apply its default

### Technical
- PreferencesService gains two new typed preferences: toneWeightEnabled (bool, default false) and toneWeight (double, default 0.4, clamped 0.0-1.0)
- PronunciationApiService.evaluate() accepts an optional toneWeight argument and encodes it as a multipart form field only when non-null
- PronunciationAssessmentViewModel reads from injected PreferencesService at both evaluation call sites (submit and auto-submit paths)
- 465 to 508 tests: 11 new unit tests for the two new PreferencesService preferences (defaults, persistence, clamping, notifyListeners), 2 new ViewModel tests asserting tone_weight is forwarded when enabled and omitted when disabled

---

## v1.0.1 | Pronunciation Polish

**Released: 2026-06-22**

### Bug Fixes
- Pronunciation scores are now computed entirely by the backend and displayed as-is; the app no longer attempts any client-side score calculation
- Pronunciation feedback is now delivered in English for clarity

### Improvements
- Introduced ReferenceAudioService to cache native speaker audio locally, eliminating redundant network fetches when replaying reference pronunciations
- Pronunciation Assessment page now preloads reference audio on open and exposes a dedicated replay button
- Added a "How to Type Vietnamese" guide widget accessible from exercise screens

### Technical
- 435 to 465+ mobile tests: new unit coverage for ReferenceAudioService, PronunciationResult model, and the new guide widget

---

## v1.0.0 | Initial release

**Released: 2025-06-05**

First public beta distributed via direct APK download.

### Features shipped
- Structured Vietnamese lesson system with 11 interactive exercise types
- Dialect-aware pronunciation scoring (MFA + PhoWhisper + CREPE) with per-syllable feedback against Hanoi or Saigon targets
- Phrase Explorer with Hanoi and Saigon accent audio (ElevenLabs TTS) and AI-generated contextual explanations
- Progress dashboard: XP, daily streaks, and achievements
- Firebase Authentication with Google Sign-In
- Django REST backend with PostgreSQL and MinIO for scoring and data persistence

### Technical
- Flutter MVVM architecture with Provider state management and GetIt dependency injection
- 232 backend tests (83% line coverage) + 465+ mobile tests (unit, widget, integration)
- Release APK signed and SHA-256 published
- Docker Swarm deployment on self-hosted server
