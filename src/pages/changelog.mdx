## v1.0.0 — Initial release

**Released: 2025-06-05**

First public beta distributed via direct APK download.

### Features shipped
- Structured Vietnamese lesson system with 9+ interactive exercise types
- AI-powered per-syllable pronunciation scoring with tone contour analysis
- Phrase Explorer with Northern and Southern accent audio playback
- Progress dashboard: XP, daily streaks, and achievements
- Firebase Authentication with Google Sign-In
- Django REST backend for scoring and data persistence

### Technical
- Flutter MVVM architecture with Provider state management and GetIt dependency injection
- 435 automated tests (unit, widget, integration)
- Release APK signed and SHA-256 published
