## v1.0.0 — Initial release

**Released: 2025-06-05**

First public beta distributed via direct APK download.

### Features shipped
- Structured Vietnamese lesson system with 11 interactive exercise types
- Dialect-aware pronunciation scoring (MFA + PhoWhisper + CREPE) with per-syllable feedback against Hanoi or Saigon targets
- Phrase Explorer with Hanoi and Saigon accent audio (ElevenLabs TTS) and AI-generated contextual explanations
- Progress dashboard: XP, daily streaks, and achievements
- Firebase Authentication with Google Sign-In
- Django REST backend with PostgreSQL and MinIO for scoring and data persistence

### Technical
- Flutter MVVM architecture with Provider state management and GetIt dependency injection
- 232 backend tests (83% line coverage) + 465+ mobile tests (unit, widget, integration)
- Release APK signed and SHA-256 published
- Docker Swarm deployment on self-hosted server
